🎓 Career Decision Support System
A smart and user-friendly Career Decision Support System developed to help students and users identify suitable career paths based on their interests, skills, and preferences. The system provides career guidance using technology-driven recommendations and interactive features.

💡 Project Objective
The main objective of this project is to help students choose the right career path based on their interests, abilities, and skills. The system aims to reduce confusion in career selection and provide better decision-making support using modern technologies.
